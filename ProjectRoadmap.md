Code Base: pygame_quiz by formazione
https://github.com/formazione/pygame_quiz

It is a small quiz game created with pygame which fits what I am looking at for making my project. 

What it does: 
It prompts the player with multiple choice questions in a window and keeps a score of what you answer. 

How I ran it: 
I ran it from the VScode terminal, then ran pyquiz5.py and it ran smoothly. 

What I learned: 
The questions are hard coded into the file itself within a list on lines 169 - 173. 
The buttons are unique in that when a button is clicked all other buttons update to false and the code marks the clicked button as true. 
The game loop sets each pass to update the buttons, labels, and tick the clock. 
Finally, the score is done by setting points to +1 if an answer is correct, if not it stays the same. 

Will I use it: 
I will borrow ideas from it, but not use it in its entirety.
